## About the project

KAYAA BLOG is a small multi-page website where five first-year IT students share what college life has been like so far: the new friends, the stressful lessons, and the moments that made us want to keep learning.

It was made as a group project for **BSIT 1-1 (Group 1)** at **FEU Roosevelt Marikina**.

## Pages

| Page | File | What it has |
|------|------|-------------|
| Home | `Blog.html` | Landing page with the hero section and a short intro to the blog |
| About Us | `about.html` | A personal introduction from each of the five members |
| Contact | `contact.html` | Group email, school details and group photo |

## Run it on your computer

1. Download or clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   ```
2. Open the folder.
3. Double-click `Blog.html` to open it in your browser.

## View it online with GitHub Pages

1. Go to the repository's **Settings** > **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, your site will be live at `https://<your-username>.github.io/<your-repo>/`.
